# graszp

**Solution architecture for working with an AI assistant: the whole project in one markdown note, under your control.**

graszp (pronounced "grasp") keeps a whole project in one markdown note, the *Solution Architecture Note* (SAN), with a fixed outline distilled from TOGAF, ArchiMate, PRINCE2, Scrum and ITIL. A short resumption note brings each new AI session up to speed, and sweeps file each session's results back into the notes. The context is plain markdown you write, read and keep.

- **Method and template:** [graszp.com](https://graszp.com) · [SAN template (markdown)](https://graszp.com/template/graszp-san-template.md)
- **Reference case:** [graszp.info](https://graszp.info), the Badinagean Nomenclature: a SKOS concept scheme in JSON-LD, planned, built and maintained with graszp
- **Repositories:** [graszp.com](https://github.com/graszp/graszp.com), the method's site · [graszp.info](https://github.com/graszp/graszp.info), the reference case
